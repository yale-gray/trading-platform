# S&P 500 individual-stock rotation (2026-10-22)

**Survivorship caveat (ADR A13): every number below uses CURRENT S&P 500 constituents
(survivorship-biased).** Names that were removed from the index (delisted, acquired, collapsed)
are absent, and winners that joined later are present for the whole period. Treat the CAGR as an
upper bound, not an estimate. The Wikipedia page no longer exposes a historical add/remove table,
so point-in-time membership was not available for free. `data/universe.py::DatedUniverse` honours
the `date_added` column (a name is only usable from the day it joined), but the backtest
strategy universe is static, so this was not applied here.

## Setup
- Universe: `src/tradebot/data/universes/sp500.csv` (503 tickers, snapshot 2026-10-21, source in
  `sp500.meta.json`). 501 used: FISV (interior gap, 2025-11-12) and HUBB (OHLC violation,
  2021-05-05) fail the data-quality checks and are not cached.
- Data: Yahoo daily, from 2005-01-01 (or listing date), adjusted. 501/503 cached; the first
  download took 111 s for all symbols.
- Strategy `strategies/stocks_momentum.yaml`: monthly; rank by 12-1 momentum (`ret` period 252,
  skip 21); eligible only above the 200-day SMA; top 15 equal weight; empty slots go to SPY.
  Parameters fixed in advance, no search.
- Run: 2007-01-03 to 2026-10-20, $10,000, 5 bp slippage, 0 fees, single-strategy risk caps
  (A16), kill switch off for the gate; production `GateConfig` and `WalkForwardConfig.defaults("equity")`,
  30% OOS.

837 closed round trips. With the 20% kill switch on, it trips on 2008-03-10 and the run ends at
CAGR 1.7% (55 trades): the switch dominates the result, so this strategy cannot be run inside the
fund's kill-switch rule at this volatility without sizing it down.

is on drawdown only; with survivorship bias the return side is flattered.

## Runtime (501 symbols, ~20 years)
- Before: about 5x slower; `_bars_at` did a pandas `get_indexer` per symbol per bar (35 of 58 s
  on a 3-year profile). Fixed in `backtest/driver.py` with a precomputed timestamp-to-row dict.
- After: fund plus SPY benchmark ~58 s; `run_validation` 545 s (~9 min, ~30 backtests).
- Remaining hotspot: `PortfolioEngine._process_bar` and `SimBroker.process_bar` convert every
  symbol's bar to Decimal each bar (`to_price` ~1.9M calls per 3 years, ~60% of time). Passing only
  held/targeted symbols would cut it further; not done (money code, not over-engineering).
